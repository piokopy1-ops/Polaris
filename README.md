# Polaris

Odzyskana wersja testowa: **Wiedźmin 3 Companion RC4 PL/EN**.

## Zawartość
- `Polaris_Wiedzmin3_COMPLETE_RC4_PL_EN.zip` — kompletna paczka aplikacji.
- `index.html` — wersja polska (po rozpakowaniu paczki).
- `index-en.html` — wersja angielska (po rozpakowaniu paczki).
- GitHub Actions automatycznie rozpakowuje paczkę i publikuje ją przez GitHub Pages po zmianach na `main`.

## Języki
W aplikacji dostępny jest przełącznik **PL / EN**. Obie wersje używają wspólnego zapisu postępu w `localStorage`.

## Status
RC4 — wersja do testów. Projekt fanowski, nieoficjalny.
